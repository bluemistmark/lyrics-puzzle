# 초성 가사 맞히기

React · TypeScript · Vite · Zustand 기반 모바일 가사 퍼즐.

## 실행 및 검증

- `npm install`
- `npm run dev`
- `npm test`
- `npm run build`

## 실제 데이터

원본: https://docs.google.com/spreadsheets/d/14CWX0pD6GDcjDhlPboF1MpZG5CAWpf_Pj_RpUA8xpqw/edit

현재 72곡, 244문제, 영어 사전 274개. NCT U / NCT 127 / NCT DREAM만 출제됩니다.

`data/lyrics.csv`와 `data/dictionary.csv`는 시트의 스냅샷입니다. `src/catalog.ts`는 생성된 게임 데이터입니다. 원본 시트는 수정하지 않습니다. 플레이 중에는 구글 계정이나 네트워크 요청 없이 번들에 포함된 데이터를 사용합니다.

### 시트 변경 반영

`npm run data:refresh`로 두 CSV를 새로 읽고 검증한 뒤 게임 데이터를 갱신합니다. 실패하면 기존 데이터를 복원합니다. 변경 반영 후 `npm test`와 `npm run build`를 실행하세요. 시트 편집이 자동으로 사이트에 실시간 반영되지는 않습니다.

이미 저장된 CSV를 다시 변환하려면 `npm run data:import`를 실행하세요.

### 시트 구조

가사: 문제ID, 곡ID, 곡명, 가수명, 가사1, 가사2, 가사3, 사용여부. 가사3은 선택이며 Y인 행만 출제합니다. 정답별칭 컬럼을 추가하면 `|`로 구분한 별칭도 읽습니다.

영어 사전: 영어, 표시발음, 추가 허용 발음. 추가 발음은 `|`로 구분합니다. 영어는 대소문자와 곧은/둥근 아포스트로피를 정규화하며 긴 구절을 먼저 매칭합니다. 구절 항목은 전체 영어 구절 또는 등록 발음으로 맞힙니다. 문장부호와 공백은 그대로 표시하며 완성률 계산에서 제외합니다.

곡ID는 곡 단위, 문제ID는 출제 구간 단위입니다. 가능한 경우 같은 곡 연속 출제를 피하며, 한 바퀴를 돌기 전에는 같은 문제를 다시 출제하지 않습니다.

제목은 공식 전체 제목, 괄호를 제외한 제목, 괄호 안 제목 및 등록 별칭을 인정합니다. 제목을 맞힌 뒤에도 가사를 끝까지 복원할 수 있습니다.

## 브라우저 기록

실제 데이터 기록은 `chosung-lyrics-live-v1`에 저장합니다. 예제 기록 `chosung-lyrics-v1`은 삭제하지 않고 별도로 보존합니다. 실제 문제에서는 새 기록으로 시작합니다. 문제별 제목 정답과 완성 횟수를 기록합니다.

한글 단어 추측은 입력과 가사 사이의 연속 두 글자 이상 공통 부분을 공개합니다. 예: 마음이 → 마음을 속 마음 공개. 한 글자 입력은 독립된 단어 전체와 일치할 때만 인정합니다. 영어는 원문/발음 사전 항목 전체가 일치해야 공개합니다.
