# 초성 가사 맞히기

모바일 우선 React · TypeScript · Vite · Zustand 프로토타입. 모든 가사는 창작 예제입니다. 실제 NCT 가사가 아닙니다.

## 실행

`npm install`, `npm run dev`. 배포 빌드: `npm run build`. 판정 테스트: `npm test`.

## 게임 규칙

- 단어 입력으로 반복된 일치 부분 전체 공개. 한 글자는 독립된 단어만 허용.
- 영어 원문 또는 지정 한글 발음 입력 가능.
- 제목을 맞힌 뒤 계속 복원하거나 다음 문제로 이동 가능.
- 제목 정답은 문제마다 한 번만 집계. 포기는 연속 정답 초기화.
- 유닛 선택, 현재 문제, 누적 기록은 localStorage 보존.
- 곡 ID와 문제 ID 분리. 문제 단위 중복 방지, 가능한 경우 같은 곡 연속 출제 방지.

## 엑셀 데이터 구조

곡 목록 시트: 곡ID(필수), 가수(필수), 유닛, 제목(필수), 정답별칭, 발매연도.

문제 목록 시트: 문제ID(필수), 곡ID(필수), 구간명, 가사1(필수), 가사2(필수), 가사3, 영어발음(영어가 있으면 필수), 사용여부(필수), 난이도.

한 곡의 여러 구간은 곡ID를 동일하게, 문제ID를 다르게 입력합니다. 별칭은 `|`로 구분합니다. 영어발음은 `summer=서머|dream=드림` 형태입니다. 영어 구절이나 동일 단어의 발음이 구간별로 다른 경우 문제에 맞는 발음을 등록합니다. 초성은 원문에서 자동 생성합니다.

현재 데이터는 src/game.ts의 songs와 questions로 연결됩니다. 엑셀 업로드/변환 기능은 아직 구현하지 않았습니다. UI의 예제 데이터 3곡에는 한 곡의 1절/후렴을 포함한 총 4구간이 각 유닛에 연결되어 있습니다.
